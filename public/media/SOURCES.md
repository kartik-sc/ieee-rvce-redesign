# Media sources

Real brand assets pulled from the existing IEEE RVCE frontend repo
(`IEEE-RVCE/IEEE-RVCE.github.io`, `master` branch,
`public/assets/images/…`). These are the branch's own assets, reused for
the redesign exploration.

## In use

- `logos/ieee_blue.png`, `logos/ieee_white.png` — official IEEE master-brand
  logo (diamond mark + wordmark). Used for site identity in header/footer.
- `logos/ieee_rvce_new_blue.png` / `_white` / `_black` — RV shield mark.
- `logos/rvce_logo.png` — RV College of Engineering crest.

## Downloaded, not in use

- `logos/MainWhite.png`, `logos/MainBlack.png` — circuit-trace decorative
  graphic. **Deliberately unused**: DESIGN.md bans blueprint/schematic/circuit
  aesthetics.
- Assorted society logos (`ieee_wie`, `ieee_sps`, …) — set is incomplete
  across the five active societies, so the Society Explorer uses a consistent
  typographic + accent-color treatment instead of a partial logo set.

## Photographic slots

No open event-photo gallery exists on the source (mostly member headshots),
and IEEE RVCE socials are auth-gated. Photographic slots therefore use the
honest designed `MediaFrame` placeholder — clearly a placeholder, never stock
or AI imagery — so real event photography can drop in later without layout
changes.
